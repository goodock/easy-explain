# easy-explain

Claude가 **14살도 이해할 수 있게, 쉽고 짧게** 설명하도록 만드는 Claude Code 출력 스타일(output style)입니다.

AI 용어·코딩 용어·영어 약자를 늘어놓거나, 필요 이상으로 길게 설명하는 것을 막아 줍니다. 대신 쉬운 말과 짧은 문장, 일상 예시로 핵심만 전달합니다.

## 무엇을 하나요

- 어려운 전문용어를 피하고, 꼭 필요하면 쉬운 말로 풀어서 설명합니다.
- 한 문장에 한 가지 생각만 담고, 군더더기를 뺍니다.
- 결론을 먼저 말하고, 자세한 설명은 필요할 때만 덧붙입니다.
- 어려운 개념은 일상생활 비유로 바꿔서 설명합니다.
- 모르는 것은 솔직하게 "확실하지 않아요"라고 말합니다.

## 예시

**이전 (어려움)**

> 이 기능은 비동기 API 호출로 데이터를 페칭해서 상태를 리렌더링합니다.

**이후 (쉬움)**

> 다른 프로그램에 "자료 좀 줘"라고 부탁해서 받아온 뒤, 화면을 새로 그려 주는 기능이에요.

## 두 가지 판

| 이름 | 언제 쓰나 |
| --- | --- |
| `easy-explain` | 개발·코딩을 하면서도 답변은 쉽고 짧게 받고 싶을 때 (코딩 지침 유지) |
| `easy-explain-not-coding` | 코딩이 아니라 일반 대화·글쓰기만 할 때 (코딩 지침 제거) |

## 설치

Claude Code CLI에서:

```
/plugin marketplace add goodock/easy-explain
/plugin install easy-explain@easy-explain
```

설치한 뒤 출력 스타일을 켭니다:

```
/output-style easy-explain
```

코딩이 아닌 일반 용도라면:

```
/output-style easy-explain-not-coding
```
