# easy-explain

Claude가 **14살도 이해할 수 있게, 쉽고 짧게** 설명하도록 만드는 Claude Code 출력 스타일(output style)입니다.

AI 용어·코딩 용어·영어 약자를 늘어놓거나, 필요 이상으로 길게 설명하는 것을 막아 줍니다. 대신 쉬운 말과 짧은 문장, 일상 예시로 핵심만 전달합니다.

## 무엇을 하나요

- 어려운 전문용어를 피하고, 꼭 필요하면 쉬운 말로 풀어서 설명합니다.
- 한 문장에 한 가지 생각만 담고, 군더더기를 뺍니다.
- 결론을 먼저 말하고, 자세한 설명은 필요할 때만 덧붙입니다.
- 어려운 개념은 일상생활 비유로 바꿔서 설명합니다.
- 모르는 것은 솔직하게 "확실하지 않아요"라고 말합니다.

## 두 가지 모드

읽는 방식을 골라서 쓸 수 있습니다. 어려운 말을 쉽게 바꾸는 규칙은 두 모드가 똑같고, **답을 어떤 모양으로 내놓는지**만 다릅니다.

| 이름 | 어떤 모양으로 답하나 | 이럴 때 |
| --- | --- | --- |
| `easy-explain` | **서술형** — 문장으로 이어서 풀어 줍니다 | 처음 배우는 내용을 이해하고 싶을 때 |
| `easy-explain-brief` | **개조식** — 핵심만 항목별로 끊어서 정리합니다 | 아는 내용을 빠르게 훑고 확인할 때 |

두 모드 모두 Claude Code의 코딩 지침을 그대로 유지합니다.

## 예시

같은 질문에 두 모드가 어떻게 다르게 답하는지 보여 줍니다.

**질문** — "서버가 뭐야?"

**`easy-explain` (서술형)**

> 손님이 주문하면 음식을 만들어 주는 식당 주방 같은 거예요. 내 컴퓨터가 "이 화면 보여 줘"라고 부탁하면, 서버가 그 자료를 만들어서 보내 줍니다. 그래서 내 컴퓨터에 없는 것도 화면에 띄울 수 있어요.

**`easy-explain-brief` (개조식)**

> 부탁을 받아 자료를 만들어 보내 주는 컴퓨터.
> - 서버 = 주문받아 음식 만들어 주는 식당 주방
> - 내 컴퓨터가 부탁 → 서버가 자료를 만들어 보냄
> - 내 컴퓨터에 없는 자료도 화면에 띄울 수 있음

## 설치

Claude Code CLI에서:

```
/plugin marketplace add goodock/easy-explain
/plugin install easy-explain@easy-explain
```

설치한 뒤 모드를 켭니다. **플러그인 이름을 앞에 붙여야 합니다.**

```
/output-style easy-explain:easy-explain
```

개조식으로 받고 싶으면:

```
/output-style easy-explain:easy-explain-brief
```

`easy-explain`처럼 이름만 쓰면 아무 오류 없이 조용히 무시되고 기본 스타일로 답합니다. 앞의 `easy-explain:`을 꼭 붙이세요.

## 모드 바꾸기

`/output-style`로 바꾸면 그다음 대화부터 계속 적용됩니다. 지금 답변 하나만 다른 모양으로 받고 싶으면 그냥 말하면 됩니다.

- "개조식으로 정리해줘"
- "풀어서 설명해줘"
